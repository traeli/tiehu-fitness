# 会议助手隐私说明

更新日期：2026-10-28

## 处理范围

会议助手在 Windows 或 macOS 本机采集用户选择的系统音频与麦克风声音，并使用本机运行的 whisper.cpp 生成文字。录音和转写文件均写入用户电脑，不上传到铁虎服务器或第三方语音服务。只有用户主动选择 OpenAI 或 DeepSeek 生成总结时，应用才会将当前会议转写文字发送给所选服务；录音文件不会发送。

## 网络请求

应用只会产生以下网络请求：

1. 用户选择 Tiny、Base、Small 或 Medium 并点击下载时，从固定地址下载对应的 Whisper 模型。该请求不包含任何会议内容。
2. 用户主动使用 Ollama 生成会议总结时，将转写发送到本机回环地址；该请求不会离开当前电脑。
3. 用户主动选择 OpenAI 生成总结时，将当前会议转写文字发送给 OpenAI。
4. 用户主动选择 DeepSeek 生成总结时，将当前会议转写文字发送给 DeepSeek。

OpenAI 和 DeepSeek 的 API Key 只保留在当前应用运行会话，不写入本地存储、会议文件或日志。

下载完成后，本地转写可离线使用。应用不创建云端会议，不使用云端实时转写或云端会议额度；OpenAI 和 DeepSeek 仅在用户主动选择对应提供方并生成总结时调用。

## 本地会议总结

用户可以在以下三种总结方式中选择：

- 本地 Ollama：使用本机已安装的 DeepSeek-R1 或其他兼容模型。应用只允许访问 `127.0.0.1`、`localhost` 或 `::1` 的 HTTP 地址，会议转写不会离开电脑。
- OpenAI：使用用户填写的模型和 API Key。生成时会把当前会议转写文字发送给 OpenAI，界面会明确提示。
- DeepSeek：使用用户填写的模型和 API Key。生成时会把当前会议转写文字发送给 DeepSeek，界面会明确提示。

无论使用哪种方式，生成的总结均与录音、转写保存在同一本地会议目录，删除会议时会一并删除。

## 本地数据

录音、转写和索引默认保存在：

```text
文稿/会议助手/录音
```

模型保存在 uTools 用户数据目录下的 `meeting-assistant/models`。用户可在应用中删除单条录音及其转写和总结，也可自行删除本地模型和录音目录。

## 权限

- macOS：系统音频录制权限；选择麦克风时还需要麦克风权限。
- Windows：选择麦克风时需要麦克风权限；系统声音通过 WASAPI Loopback 在本机采集。

权限只用于当前设备上的录音和识别，不用于后台监听。退出插件或停止会议后，采集与识别进程会停止。

## 用户提示

开始录制前，请确认你有权记录会议，并按所在地法律和组织制度向其他参会者履行必要的告知或取得同意。

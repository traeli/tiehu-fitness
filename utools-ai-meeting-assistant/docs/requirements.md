# 会议助手 uTools 插件需求文档

版本：V1.0  
状态：需求基线  
项目类型：uTools 桌面插件  
首发平台：macOS 13+、Windows 10+

## 1. 产品定位

会议助手是一款轻量 uTools 插件。用户从 uTools 搜索“会议助手”即可开始记录会议，插件把音频发送给后端完成实时转写，并在会议结束后展示结构化纪要。

产品核心体验：

> 一个按钮开始会议，一个按钮结束会议。

插件不在本地运行大型 AI 模型，不承担 ASR 或 LLM 推理。AI 能力由 `tiehu-fitness` 项目的后端 API 提供。

## 2. 产品目标

- 用户在 30 秒内理解产品并开始第一次会议。
- 一次正常会议可以完成“采集—转写—停止—总结—导出”闭环。
- 插件在录制期间保持轻量，不因长会议无界占用内存。
- 用户清楚知道音频是否发送到云端、是否保留，并可以删除数据。
- 首期验证真实转写和纪要质量，而不是堆叠大量会议管理功能。

## 3. 目标用户与场景

### 3.1 线上会议

用户参加 Zoom、腾讯会议、飞书会议或 Google Meet，同时打开插件记录讨论，结束后获得摘要、决策和待办。

### 3.2 技术会议

开发团队讨论架构、Bug 和技术选型。纪要重点提取技术决策、风险、负责人和截止时间。

### 3.3 商务会议

销售或客户成功团队记录客户需求、异议、下一步行动和跟进时间。

## 4. 版本范围

### 4.1 V1.0 MVP

- uTools 指令打开插件。
- 通过 uTools 临时用户令牌登录后端。
- 开始和停止会议。
- 获取麦克风权限并采集单声道音频。
- 实时发送音频并展示最终转写片段。
- 显示会议时长、连接状态和处理状态。
- 短时断网后的重连与音频序号去重。
- 停止后触发最终转写和 AI 纪要。
- 展示主题、摘要、主要讨论、决定、待办和风险。
- Markdown 导出。
- 用户选择是否在云端保留最终录音。
- 查看并删除历史会议的后端接口预留；首屏历史列表可在 MVP 后半程实现。

### 4.2 V1.0 系统音频说明

原始设想同时把“系统声音录制”列为必须功能，又在 MVP 清单中只列“麦克风录音”。本项目按以下方式收敛：

- 首个可联调版本同时采集 uTools 系统音频和可选麦克风，混成单轨送往 ASR 并本地保存。
- 录音模块必须保留 `AudioRecorder` 接口，不能把业务状态绑定到 `MediaRecorder`。
- macOS 系统音频采用 ScreenCaptureKit，Windows 采用 WASAPI Loopback；发布前仍必须分别完成权限、输出设备和真实会议软件兼容性验证。
- 未通过系统音频验证前，产品不能宣称已完整记录会议应用的播放声音。

### 4.3 V1.1

- 系统音频与麦克风的动态 ducking、分轨和更强的剪裁保护。
- 屏幕或指定窗口录制。
- 最终录音/视频的断点续传。
- TXT/PDF 导出。
- 关键帧、OCR 和截图理解。

### 4.4 V2.0

- 实时 VLM 分析。
- PPT、文档、代码和表格理解。
- 多说话人分离、说话人校正和授权声纹。
- 第三方任务系统同步。
- 团队空间、知识库、权限和企业审计。

## 5. 核心用户流程

### 5.1 首次进入

1. 用户在 uTools 搜索“会议助手”或“AI会议助手”。
2. 插件读取 uTools 登录状态。
3. 插件获取短期服务端临时令牌并发送给本项目后端换取业务访问令牌。
4. 插件展示音频传输、第三方 AI 处理和录音保留说明。
5. 用户同意后可以开始会议。

uTools 未登录、后端换取失败或隐私同意未完成时，不允许进入录制状态。

### 5.2 开始会议

1. 用户选择是否保留云端录音。
2. 用户点击“开始会议”。
3. 插件请求麦克风权限。
4. 插件创建后端会议并取得短期实时转写 session ticket。
5. 插件建立 WebSocket，确认服务端接受的编码参数。
6. 插件开始采集并发送音频，界面显示“录制中”和计时。

权限拒绝、会议创建失败或 WebSocket 未建立时，界面必须显示失败原因，不能显示假录制状态。

### 5.3 实时转写

- 最终片段按会议时间顺序显示。
- 临时片段可以更新，但不能在历史文本中形成重复内容。
- MVP 的说话人显示为“发言人”或 `speaker_1`，不承诺真实姓名。
- 断线时显示“正在重连”，而不是继续假装实时在线。
- 重连使用最后确认序号恢复；服务端拒绝重复片段。
- 无法恢复时继续保留本地临时音频，并明确提示实时文本可能延迟。

### 5.4 停止和总结

1. 用户点击“停止会议”。
2. 插件停止采集并释放媒体设备。
3. 插件结束实时会话，完成需要保留的最终录音上传。
4. 插件幂等调用停止会议接口。
5. 本地录音保存成功后立即恢复可交互状态，纪要在服务端异步生成。
6. 插件在后台有界轮询处理状态；用户也可以在最近会议详情中查看进度。
7. 处理失败时允许重试失败阶段，不要求重新录制。

退出 uTools 主窗口不等于停止会议。只要插件进程仍存活，录制应继续；进程即将被结束时必须提示用户或执行可恢复的安全停止。

### 5.5 导出和删除

- Markdown 导出调用 uTools 保存对话框，由用户选择文件位置。
- 文件名默认使用安全处理后的会议主题。
- 插件不允许静默覆盖未获用户确认的任意文件。
- 删除会议需要二次确认；后端完成跨服务清理前显示“删除中”。

## 6. 页面需求

### 6.1 主界面

主界面至少包含：

- 产品名称。
- 当前状态和会议计时。
- 开始/停止主按钮。
- “保留云端录音”选项。
- 屏幕录制的后续版本占位说明。
- 实时转写区域。
- 错误、断线和 AI 处理状态。
- 纪要区域与 Markdown 导出按钮。

### 6.2 最近会议详情

- 左侧按开始时间倒序展示 uTools 本地录音，包含时长、文件大小和会议标识。
- 右侧固定展示本地录音播放器和服务端会议状态。
- 右侧提供“AI 会议总结”和“完整转写”两个标签页。
- AI 总结展示主题、摘要、关键讨论、决定、待办、风险、模型和生成时间。
- 完整转写按时间展示，点击片段可以跳转本地录音播放位置。
- 总结处理中自动刷新；失败时展示稳定原因和重新生成入口。
- 本地音频读取失败不能阻止服务端转写和总结展示，反之亦然。
- 删除本地录音需要二次确认。

## 7. 状态要求

客户端状态：

```text
idle
  -> starting
  -> recording
  -> stopping
  -> processing
  -> completed / partially_completed / failed / cancelled
```

- 同一时间只允许一个开始或停止命令执行。
- `starting` 阶段不能重复点击开始。
- 只有 `recording` 可以停止。
- 终态可以开始下一场会议。
- 状态必须来源于显式转换，不能由多个组件分别维护。

## 8. 隐私和安全需求

- 首次录制前明确告知音频会发送到云端 ASR/LLM。
- `retain_audio=false` 表示不持久化可回放录音，不表示音频从未传输到云端。
- 访问令牌不写日志、不拼进普通 URL、不写入导出文件。
- uTools 临时令牌只用于一次后端换取，不能长期保存。
- Renderer 不直接使用任意 Node 文件系统和进程执行能力。
- Preload 只暴露经过验证的最小方法。
- 音频缓冲写入插件专用目录，不能使用不受控路径。
- 用户主动保存 Markdown 时才写入所选路径。
- 转写正文、纪要和音频不得进入埋点或崩溃日志。

## 9. 非功能需求

- 冷启动目标小于 2 秒，在真实 uTools macOS 环境测量。
- 正常录制内存目标小于 200 MB；不得把整场原始音频长期保存在 Renderer 数组中。
- 界面交互不因上传或 AI 处理阻塞。
- 音频分片、未确认队列和重连缓存有配置上限。
- 录制资源具有唯一 owner，停止、异常和窗口销毁均释放媒体 track。
- 深色模式、键盘操作和基本屏幕阅读器标签可用。
- V1.0 同时支持 macOS 13+ 和 Windows 10+；所有平台差异通过原生 adapter 隔离，不在业务和组件中散落条件判断。

## 10. 验收标准

1. `npm run build` 生成可被 uTools 开发者工具识别的 `dist/plugin.json`。
2. 通过“会议助手”指令能打开插件。
3. 用户允许麦克风后，状态才进入“录制中”。
4. 拒绝权限时显示错误并释放已创建资源。
5. 录制三十分钟没有与会议时长线性增长的 Renderer 音频内存。
6. 实时最终文本按序展示，重复帧不形成重复片段。
7. 短时断网有可见重连状态并可恢复。
8. 停止按钮幂等，媒体 track 被释放。
9. 纪要结构完整，空数组有合理空态。
10. Markdown 导出 UTF-8 正确，表格中的换行和竖线被转义。
11. 未授权用户不能读取、导出或删除他人会议。
12. 选择不保留录音时，会议仍有转写和纪要，但后端无可回放原始录音。

## 11. 商业化预留

插件展示后端返回的分钟额度和订阅状态，不在客户端自行判定权益。后续可支持：

- 免费版：每月有限分钟数。
- 会员版：更高或不限分钟数、高级模型、历史搜索。
- 企业版：团队、知识库、权限和审计。

所有权益以服务端结果为准；客户端状态不能作为计费或授权依据。

## 12. 待产品确认

- 原生辅助程序在 uTools 市场跨平台包中的签名、审核与升级策略。
- 云端原始录音默认保留期限。
- 用户关闭主窗口但仍在录制时的产品提示方式。
- MVP 是否需要标题编辑、手工修正转写和手工修正说话人。
- 免费分钟数与单场最大时长。
- 首选 ASR/LLM Provider 及故障切换策略。

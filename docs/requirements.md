# Web/小程序需求整理

## 产品定位

面向普通健身用户的辅助工具，完成“登录建档、识别器材、学习动作、纠正姿势、执行计划、记录进步”的闭环。

## core-service 用户与训练模块

- 当前 Web 端使用邮箱、密码注册和登录，便于页面开发与接口联调。
- 后续小程序继续使用微信 `wx.login` 首次登录自动注册，无独立微信注册页面。
- Access Token、Refresh Token、退出和设备会话。
- 用户昵称、头像和可选手机号绑定。
- 健身目标、经验、频次、时长、可用器材和伤病限制。
- 训练计划生成、训练日、组数次数重量、RPE/RIR、休息计时。
- 训练历史、个人最佳、打卡、连续训练天数和提醒偏好。
- 隐私协议及敏感数据授权记录。

## core-service 内容模块

- 器材名称、说明、调节方法和安全提示。
- 动作、目标肌群、难度、步骤、呼吸节奏和常见错误。
- 教学视频元数据、封面、版本和运营审核。
- 识别结果对应的推荐动作和替代动作。

## vision-service 功能

- 图片和视频上传凭证、媒体状态和生命周期。
- 器材候选识别、置信度、人工纠错反馈。
- 视频质量检查、动作次数、动作阶段和关节轨迹。
- 错误时间点、姿势评分、风险提示和历史对比。
- 异步任务状态、模型版本、结果追溯和失败重试。

## 安全与合规

- 姿势分析属于健身辅助，不是医疗诊断。
- 原始视频使用对象存储直传和短期签名 URL。
- AI 结果记录模型版本、置信度、任务 ID 和输入质量。
- 密码只保存 bcrypt 哈希；OpenID、session_key、手机号和伤病信息按敏感数据处理。
